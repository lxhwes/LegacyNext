# forever-bump (the forever-tools beta-build-bump skill) greps each build's diff for these and
# pulls out the hunks that mention them, so a 3,000-line build diff collapses to the handful of
# lines that can actually break us. A triage filter, not a contract: a symbol missing from this
# file still shows up in full.diff. Add a line whenever Api/ starts calling something new.
#
# forever-bump also unions this list with every C_Namespace.Function reference under
# FT_ADDON_DIRS (.claude/forever-tools/config.env), so namespaced calls are watched without
# editing this file. That auto-discovery only catches namespaced calls, which is why the bare
# FrameXML globals and the constant names below are listed by hand.
