# Symbols LegacyNext depends on. One per line; blank lines and # comments ignored.
#
# bump.sh greps the vendored diff for these and pulls out the hunks that mention them,
# so a 3,000-line build diff collapses to the handful of lines that can actually break us.
# This is a triage filter, not a contract: a symbol missing from this file still shows up
# in full.diff. Add a line whenever Api/ starts calling something new.
#
# bump.sh also unions this list with every C_Namespace.Function reference it finds under
# LegacyNext/, so symbols added to the addon are watched without editing this file. That
# auto-discovery only catches namespaced calls, which is why the bare FrameXML globals and
# the constant names below are listed by hand.
